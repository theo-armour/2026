# GitHub + Markdown: The Simplest Way to Share Knowledge

## Why GitHub?

GitHub is the world's largest collection of shared knowledge — over 400 million repositories of code, research, and ideas. Anyone can contribute, and nearly all critical software depends on it.

## Why Markdown?

Markdown is **plain text** that looks good everywhere. No special software needed. This file you're reading right now *is* Markdown.

## How to GitHub

1. Go to [github.com](https://github.com) and create a free account
2. Click **New Repository** and give it a name
3. Click **Add a README** — you just published your first file

To edit: click any file, press the pencil icon, make changes, and hit **Commit changes**. Done. Every save is a version you can go back to.

## How to Markdown

Here's everything you need to know:

### Headings

```
# Big heading
## Smaller heading
### Even smaller
```

### Text styling

This is **bold**, this is *italic*, and this is a [link](https://github.com).

```
This is **bold**, this is *italic*, and this is a [link](https://github.com).
```

### Bullet lists

- First item
- Second item
- Third item

```
- First item
- Second item
- Third item
```

### Numbered lists

1. Do this first
2. Then this
3. Then this

```
1. Do this first
2. Then this
3. Then this
```

### Images

```
![Description](https://example.com/image.png)
```

---

That's it. You now know GitHub and Markdown.

Create a `.md` file, write something useful, commit it, and share the link. Knowledge transferred.
